## Description

A lightweight package containing a filesystem abstraction for IRODS, ftp, scp, smb, etc.

## Usage

The package can be installed from our local package repository, using:

  export PIP_EXTRA_INDEX_URL="https://${GITLAB_USER}:${GITLAB_TOKEN}@gitlab.rivm.nl/api/v4/groups/133/packages/pypi/simple"
  pip install idms-common-filesys
